1. 쿠팡 아이템위너란?

정의

동일한 상품을 여러 판매자가 판매할 때, 쿠팡이 해당 상품들을 하나의 대표 상품군으로 자동 분류(묶음)한 뒤, 가격/배송/고객응대 등에서 가장 우수한 판매자 1명만을 선정하여 대표로 노출시키는 "승자독식 시스템"

작동 원리

  • 쿠팡 AI 알고리즘이 상품명, 이미지, 상세설명, 브랜드, 바코드 등을 분석하여 "동일 상품" 판단 → 자동 매칭
  • 이미지 임베딩과 텍스트 임베딩 기술로 유사성을 수치적으로 표현 → 중복 상품 자동 탐지

아이템위너 선정 기준

  • 판매가 + 배송비 합산: 낮을수록 유리
  • 단위당 판매가격: 2024년 7월 28일부터 추가, 낮을수록 유리
  • 재고현황: 충분할수록 유리
  • 출고소요기간: 짧을수록 유리
  • 판매자점수: 높을수록 유리 (정시출고, 정시배송, 주문이행률, 24시간 내 답변)

먼저 등록했다고 계속 위너가 되는 것이 아니며, 실시간 경쟁에 따라 위너가 변동됨

2. 아이템위너 매칭이 되면 생기는 문제점

  • 노출 박탈: 위너가 아닌 상품은 메인 검색 결과에 거의 노출 안됨. "다른 판매자 보기" 버튼을 누르지 않는 한 볼 수 없음
  • 리뷰/판매 실적 귀속: 내가 쌓은 리뷰와 판매 실적이 위너로 선정된 다른 판매자의 페이지에 귀속
  • 끝없는 가격 경쟁: 최저가 유지를 위한 출혈 경쟁 불가피. 쿠팡 직매입과 묶일 경우 역마진 위험
  • 쿠팡 추천가 압박: 추천가를 따라가야 하는 경우가 많아 마진 확보 어려움
  • CS 부담: 위너로 선정되면 다른 판매자가 판매한 건에 대한 문의까지 처리해야 할 수 있음
  • 상세페이지 통제 불가: 묶이면 다른 셀러의 상세페이지가 채택될 수 있음

3. 아이템위너 매칭을 피하는 구체적인 방법들

3-1. 상품명 차별화 전략

  • 브랜드명/사업자명을 상품명 앞에 배치: "온채널마켓 여성 반팔 티셔츠"처럼 자신만의 식별자
  • 도매처 상품명 그대로 사용 금지: 같은 도매처에서 소싱한 다른 셀러와 높은 확률로 묶임
  • 고유 키워드 삽입: 상품 특징을 나만의 표현으로 재작성
  • 구성 정보를 상품명에 반영: 세트 구성이나 사은품 정보를 명시하여 단품과 차별화

3-2. 옵션/구성 차별화

  • 나만의 옵션명 작성: "블랙" 대신 "브랜드명 블랙"처럼 고유 키워드 삽입
  • 옵션 구성 자체 변경: 기존 상품과 다른 색상/사이즈 조합
  • 수량 구성 변경: 1개 단품 → 2개 세트, 3개 세트 등으로 변경 → 다른 상품으로 인식

3-3. 바코드/모델명 관리

  • 카탈로그 매칭 거부: 등록 시 "직접 등록할게요" 선택 (가장 중요!)
  • 제조사/브랜드 정보 변경: 도매처 정보 그대로 사용 X → 자신의 브랜드명으로 변경
  • 모델명 고유화: 자신만의 고유 모델명 부여. 도매처 모델번호 그대로 입력 금지

3-4. 이미지 차별화

쿠팡 AI는 이미지 유사도를 분석하므로 이미지 차별화가 매우 중요

  • 직접 촬영: 가장 확실한 방법
  • AI 툴 활용: 썸네일 각도 변경, 배경 차별화
  • 포토룸 활용: 누끼 + 다른 배경 합성
  • 부분 확대 이미지: 제품 사진을 부분 확대하여 썸네일로 사용
  • 1688 등 해외 소스 활용: 국내 도매몰에 없는 이미지 확보
  • 브랜드 합성: 상품 이미지에 브랜드 로고를 포토샵으로 합성
  • 모델 착용 사진: 사람이 착용한 사진 → 초상권 주장 가능 → 이미지 도용 방지
  • 도매처 이미지 그대로 사용 절대 금지

3-5. 묶음 상품/세트 구성

  • 여러 아이템 묶음: 단일 상품 → 관련 상품과 함께 세트 구성 → 다른 상품으로 분류
  • 사은품 추가: 스티커, 파우치, 소형 액세서리 등 간단한 사은품 포함
  • 합배송 활용: 다른 상품과 합배송 요구 → 아이템위너 분류 회피

3-6. 카테고리 선택 전략

  • "직접 등록할게요" 선택: 판매방식 "판매자배송" → 카탈로그 매칭 단계에서 거부
  • 세부 카테고리 차별화: 같은 상품도 다른 카테고리로 등록 가능 (단, 검색 노출에 부정적 영향 가능 → 신중히)

4. 자체 상품 페이지 만드는 방법 (개별 등록)

등록 절차 (8단계)

1단계: 쿠팡윙 > 상품관리 > 상품등록 → 카탈로그 매칭에서 "직접 등록할게요" 선택, 판매방식 "판매자배송"

2단계: 상품명 100글자 이내 작성, 브랜드명/사업자명을 앞에 배치, 적절한 카테고리 선택

3단계: 재고수량(초보자 100개 이하 권장), 옵션(고유 옵션명), 판매가 설정

4단계: 차별화된 이미지와 상세설명 등록

5단계: 브랜드(자신의 브랜드명), 제조사, 인증정보 입력

6단계: 검색어(최대 20개)와 검색필터 입력

7단계: 상품정보제공고시 작성

8단계: 배송 및 반품/교환 정보 설정 (출고일 2~3일 권장)

핵심: 1단계에서 카탈로그 매칭을 하지 않는 것이 가장 중요

5. 아이템위너에 걸렸을 때 대처 방법

방법 1: 쿠팡 온라인 문의를 통한 분리 요청

경로: 쿠팡윙 > 온라인 문의 > 상품관리 > 상품수정요청

절차:

  1. "상이한 상품과 잘못 결합되어 있으니, 분리해주세요" 선택
  2. 등록상품 ID(VendorInventory ID) 숫자로 정확히 기재
  3. 분리 필요한 상품의 노출상품 ID(Product ID), 옵션 ID(Vendoritem ID) 기재
  4. 왜 다른 상품인지 구체적으로 작성

성공 확률 높이는 방법:

  • 옵션 구성/브랜드 차이 증빙 자료 첨부
  • 상품 구성, 포장, 브랜드 차이를 사진으로 증명
  • 10개 이상 요청 시 대량문의 엑셀 템플릿 사용
  • 중복 요청 주의 (처리 지연/반려)

방법 2: 상표권을 활용한 분리

절차:

  1. 쿠팡 판매 페이지 "신고하기" 버튼 또는 cm112@coupang.com으로 지식재산권 침해 신고서 제출
  2. 상표권자명, 등록번호(제40-000000호 형식) 기재
  3. 제목: "상표권침해로 인한 아이템위너 매칭 분리 및 향후 매칭 방지 요청"

필수 첨부 서류:

  • 지식재산권 침해 신고 양식
  • 마스킹한 신분증
  • 상표등록증 및 등록원부
  • 브랜드가 표시된 상품 사진

처리 시간: 약 12시간

방법 3: 상품 정보 전면 수정

이미 묶인 상태에서 상품명, 이미지, 옵션, 상세페이지를 전면 수정 → 쿠팡 시스템이 "다른 상품"으로 재인식하도록 유도

6. 아이템위너 vs 독자 상품페이지 장단점

아이템위너 참여

  • 장점: 위너 선정 시 노출/판매 독점, 누적 리뷰 활용, 소비자 신뢰도, 별도 비용 없음
  • 단점: 위너 아니면 노출 거의 불가, 끝없는 가격 경쟁, 추천가 압박, 리뷰/실적 유실, 상세페이지 통제 불가

독자 상품페이지

  • 장점: 가격 경쟁에서 벗어남, 리뷰/실적 온전히 자신 것, 상세페이지 자유 관리, 브랜드 가치 구축
  • 단점: 초기 리뷰/실적 처음부터 쌓아야 함, 검색 노출 불리, 차별화 추가 비용, 상표등록 비용 (약 30~60만원)

7. 실전 셀러들의 아이템위너 회피 노하우

노하우 1: 상표권 등록이 최우선

  • 가장 확실한 방법
  • 표준 심사: 1년 4개월 이상 / 우선심사: 약 2~3개월
  • 비용: 특허청 관납료 16만원 + 대리인 수수료 15~30만원 = 총 30~60만원
  • 상표를 제품 포장에 명확히 표시 + 등록상표 기호 → 침해자 악의 추정 가능

노하우 2: 도매 상품 정보 절대 그대로 사용 X

  • 도매처(도매꾹, 도매매, 1688)에서 받은 상품명, 썸네일, 상세 이미지, 제조사 정보를 그대로 사용하는 것이 매칭의 가장 큰 원인
  • 모든 정보를 자신만의 것으로 변경

노하우 3: 세트/묶음 판매가 현실적 대안

  • 2개 세트, 3개 세트 구성 → 다른 상품으로 분류
  • 간단한 사은품(스티커, 파우치) 하나만 추가해도 효과

노하우 4: 이미지 직접 촬영 또는 AI 가공

  • 포토룸/AI 도구로 배경 변경, 촬영 각도 변경, 브랜드 로고 합성
  • 1688 등 해외 사이트에서 국내 도매몰에 없는 이미지 확보

노하우 5: 개별 등록 시 카탈로그 매칭 거부

  • 상품 등록 첫 단계에서 "직접 등록할게요" 선택이 핵심

노하우 6: 옵션명에 고유 식별자 삽입

  • "블랙" → "브랜드명 블랙"

노하우 7: 재고 관리 철저

  • 로켓그로스 품절 시 경쟁 셀러가 위너 차지 → 실시간 재고 관리 필수

8. 쿠팡 정책상 주의사항

  • 허위 정보 등록 주의: 매칭 회피용 허위 정보 → 쿠팡 정책 위반 제재
  • 주문 취소 페널티: 재고 낮게 설정 후 주문 취소 → 판매자점수 하락
  • 카테고리 부적합 등록 주의: 맞지 않는 카테고리 등록 → 카테고리 이동/노출 제한
  • 단위당 판매가격 기준: 묶음 구성 시 개당/용량 기준 환산 단위가격이 기준 초과 시 노출 제한
  • 노출제한 해제: 쿠팡윙 > 상품관리 > 상품조회/수정 > 옵션수정에서 추천가 적용 후 심사
  • 쿠팡 직매입과의 경쟁: 로켓배송 직매입과 묶일 경우 가격/배송 경쟁 불가 → 아예 피하거나 구성을 완전히 다르게
