쿠팡 광고 종류

1. 쿠팡 CPC 광고 (검색광고)

  • 고객이 검색했을 때 상단에 노출되는 광고
  • 클릭당 과금 (CPC: Cost Per Click)
  • 가장 기본이고 효과가 검증된 광고

2. 브랜드 광고

  • 브랜드 전용 배너 형태
  • 로켓배송/로켓그로스 셀러만 가능
  • 비용이 높아 초보에겐 비추천

3. 디스플레이 광고 (CPA)

  • 쿠팡 메인, 카테고리 페이지 등에 배너 노출
  • 구매 전환 시 과금 (CPA: Cost Per Action)
  • 전환율이 높은 상품에 적합

광고 시작 전 준비사항

광고 전에 반드시 갖춰야 할 것

  • 상품 이미지 퀄리티가 높은가 (클릭률에 직접 영향)
  • 상품명에 핵심 키워드가 잘 들어가 있는가
  • 가격 경쟁력이 있는가 (광고해도 가격이 비싸면 전환 안 됨)
  • 리뷰가 최소 5개 이상 있는가 (리뷰 0개는 광고비 낭비)
  • 상세페이지가 구매를 유도할 만큼 잘 되어있는가

광고를 하면 안 되는 경우

  • 리뷰가 0개인 신규 상품 (먼저 리뷰 확보가 우선)
  • 마진이 너무 낮은 상품 (광고비 빠지면 적자)
  • 경쟁이 너무 치열한 레드오션 키워드 (입찰가가 높아 수익성 없음)

CPC 광고 세팅 방법

캠페인 구조

  • 캠페인 1개당 상품 1개를 추천 (관리가 편함)
  • 캠페인명은 알아보기 쉽게: "여성반팔티_화이트_CPC" 형태

키워드 설정

  • 자동 키워드: 쿠팡이 알아서 매칭 (초반에 데이터 수집용으로 활용)
  • 수동 키워드: 직접 키워드를 넣고 입찰가 조절 (효율 관리에 필수)

추천 전략

  1. 처음 1~2주: 자동 키워드로 운영하면서 데이터 수집
  2. 데이터 확인: 어떤 키워드로 클릭/전환이 발생했는지 분석
  3. 효율 좋은 키워드만 수동으로 옮기고 입찰가 올리기
  4. 효율 나쁜 키워드는 제외 키워드로 등록

입찰가 설정

초반 입찰가

  • 쿠팡 권장 입찰가의 70~80%에서 시작
  • 너무 낮으면 노출 자체가 안 됨
  • 너무 높으면 광고비만 나가고 수익 없음

입찰가 조절 기준

  • ROAS(광고수익률) 200% 이상이면 입찰가 유지 또는 소폭 상승
  • ROAS 100~200%이면 키워드별로 분석 후 조정
  • ROAS 100% 이하면 입찰가 낮추거나 키워드 제외

ROAS 계산

ROAS = (광고로 발생한 매출 / 광고비) × 100

예: 광고비 10만원, 매출 30만원 → ROAS 300%

광고 효율 높이는 핵심 팁

1. 클릭률(CTR) 올리기

  • 메인 이미지가 가장 중요 (경쟁 상품보다 눈에 띄어야 함)
  • 가격이 경쟁력 있으면 클릭률 자연 상승
  • 로켓배송/로켓그로스 배지가 있으면 클릭률 높아짐
  • 리뷰 개수와 별점이 높으면 신뢰도 상승

2. 전환율 올리기

  • 상세페이지 첫 3장이 승부 (고객은 끝까지 안 봄)
  • 무료배송 설정 (배송비 별도보다 전환율 훨씬 높음)
  • 쿠폰 설정 (할인쿠폰 있으면 전환율 상승)
  • 리뷰 관리 (부정 리뷰에 빠르게 대응)

3. 불필요한 광고비 줄이기

  • 전환 없는 키워드는 과감히 제외
  • 시간대별 성과 분석 후 비효율 시간대 광고 중단
  • 일일 예산 설정으로 과도한 지출 방지
  • 주 2~3회 광고 성과 리포트 확인

일일 예산 가이드

테스트 단계 (1~2주)

  • 상품당 일 5,000~10,000원
  • 목적: 키워드 데이터 수집, 클릭률/전환율 파악

최적화 단계 (3~4주)

  • 효율 좋은 상품: 일 10,000~30,000원으로 증액
  • 효율 나쁜 상품: 광고 중단 또는 일 3,000원으로 축소

확장 단계

  • ROAS 200% 이상 유지되는 상품만 예산 확대
  • 한 번에 큰 폭으로 올리지 말고 20~30%씩 점진적으로

광고 성과 분석 주기

매일 확인

  • 일일 광고비 소진 현황
  • 비정상적인 클릭 급증 여부

주 2~3회 확인

  • 키워드별 클릭률, 전환율, ROAS
  • 제외할 키워드 정리
  • 입찰가 조정

월 1회 확인

  • 전체 광고 수익성 분석
  • 상품별 광고 계속/중단 판단
  • 다음 달 광고 예산 계획

초보 셀러 광고 실수 TOP 5

  1. 리뷰 없는 상품에 광고비 쏟기 → 먼저 리뷰 5개 이상 확보
  2. 자동 키워드만 계속 돌리기 → 반드시 수동 키워드로 전환 필요
  3. 광고 세팅 후 방치 → 최소 주 2회 성과 확인 필수
  4. ROAS 안 보고 매출만 보기 → 매출 높아도 광고비가 더 크면 적자
  5. 모든 상품에 광고 걸기 → 마진 높고 경쟁력 있는 상품만 선별
