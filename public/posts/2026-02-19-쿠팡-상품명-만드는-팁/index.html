기본 원칙

  • 쿠팡 상품명은 최대 100자 (공백 포함)
  • 핵심 키워드를 앞쪽에 배치할수록 검색 노출에 유리
  • 고객이 실제로 검색하는 단어를 사용

상품명 구조 (권장 순서)

브랜드명 + 핵심키워드 + 상품특성 + 소재/사이즈/색상 등 부가정보

예시: [브랜드] 여성 오버핏 반팔 티셔츠 루즈핏 여름 면 라운드넥 빅사이즈

키워드 선정 방법

1. 쿠팡 자동완성 활용

  • 쿠팡 검색창에 핵심 단어를 입력하면 자동완성 키워드가 노출됨
  • 이 키워드들이 실제 고객이 많이 검색하는 단어
  • 예: "여성 티셔츠" 입력 → "여성 티셔츠 반팔", "여성 티셔츠 오버핏" 등

2. 쿠팡 연관검색어 확인

  • 검색 결과 하단에 나오는 연관검색어도 참고
  • 경쟁 상품의 상품명에서 공통적으로 사용하는 키워드 파악

3. 네이버 데이터랩/키워드 도구

  • 네이버 쇼핑 검색량으로 키워드 수요 확인
  • 검색량 대비 경쟁 상품 수가 적은 키워드가 유리

상품명 작성 팁

DO (해야 할 것)

  • 메인 키워드를 상품명 앞쪽에 배치
  • 동의어/유사어를 함께 넣기 (예: 반팔 + 반소매, 오버핏 + 루즈핏)
  • 시즌 키워드 포함 (봄, 여름, 가을, 겨울)
  • 타겟 고객 키워드 포함 (여성, 남성, 유아, 빅사이즈)
  • 소재 키워드 포함 (면, 린넨, 쉬폰)
  • 용도/상황 키워드 포함 (데일리, 출근룩, 데이트룩)

DON'T (하지 말아야 할 것)

  • 특수문자 남용 금지 (★, ♥, ◆ 등) → 검색에 불리
  • 의미 없는 키워드 나열 금지 → 쿠팡 페널티 가능
  • 과장/허위 표현 금지 (1등, 최고, 대박 등)
  • 경쟁사 브랜드명 사용 금지 → 지식재산권 침해
  • 같은 키워드 반복 금지 (예: 티셔츠 티셔츠 반팔티셔츠)

카테고리별 상품명 예시

여성의류 - 티셔츠

[브랜드] 여성 오버핏 반팔티 여름 면 루즈핏 라운드넥 무지 티셔츠 빅사이즈

여성의류 - 원피스

[브랜드] 여성 플라워 원피스 봄 여름 쉬폰 롱원피스 플레어 데이트룩

뷰티 - 스킨케어

[브랜드] 히알루론산 수분크림 보습 페이스크림 건성피부 데일리 50ml

상품명 최적화 체크리스트

  • [ ] 100자 이내인가?
  • [ ] 핵심 키워드가 앞쪽에 있는가?
  • [ ] 고객이 실제 검색할 단어를 포함했는가?
  • [ ] 동의어/유사어를 넣었는가?
  • [ ] 시즌, 타겟, 소재, 용도 키워드가 있는가?
  • [ ] 특수문자를 남용하지 않았는가?
  • [ ] 같은 키워드를 반복하지 않았는가?
  • [ ] 과장/허위 표현이 없는가?

상품명 테스트 방법

  1. 작성한 상품명의 핵심 키워드로 쿠팡에서 직접 검색
  2. 상위 노출 상품들의 상품명과 비교
  3. 빠진 키워드가 있으면 추가
  4. 등록 후 1~2주 뒤 노출 순위 확인하고 상품명 수정
