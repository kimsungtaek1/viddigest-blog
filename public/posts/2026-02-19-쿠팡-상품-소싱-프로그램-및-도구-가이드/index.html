1. 아이템스카우트 (ItemScout)

  • 공식 사이트: https://itemscout.io/
  • 형태: 웹사이트 + 크롬 확장 프로그램 + 모바일 앱

주요 기능

  • 키워드 분석: 키워드 검색량, 경쟁률, 쇼핑성 키워드 여부, 기존 셀러 판매 정보를 한눈에 확인
  • 아이템 발굴: 쇼핑 카테고리별 인기 키워드의 수요와 공급 상황 파악. 카테고리와 기간 설정 시 인기 키워드 500위까지 표시
  • 랭킹 추적: 네이버 쇼핑에 등록된 상품이 특정 키워드에서 몇 위에 노출되는지 확인
  • 경쟁강도 지표: 상품 수를 총검색 수로 나눈 값. 경쟁강도가 1보다 크면 공급 > 수요이므로 진입이 어려움

사용법

메인 화면 검색창에 소싱하고 싶은 카테고리 검색 → 적합한 키워드 발굴. 검색수가 어느 정도 있으면서 경쟁강도가 낮은 키워드를 선택하는 것이 핵심

2. 판다랭크 (PandaRank)

  • 공식 사이트: https://pandarank.net/
  • 형태: 웹사이트

주요 기능 4가지

  • 키워드 분석: 검색량, 연관 키워드, 광고 효율, 시장 상황 종합 분석. CPC 예측, 현재 1등 상품 확인 가능
  • 상품 분석: 등록한 상품의 건강 상태 체크, 다른 상품 대비 취약한 부분 확인
  • 상품 순위: 특정 키워드 검색 시 내 상품이 1페이지에 노출되는지 확인
  • 키워드 찾기: 최근 인기 단어, 경쟁 강도, 가격 분포 → "지금 올리면 반응이 있는 상품군"과 "이길 수 있는 가격대"를 동시 파악

활용법

카테고리별 인기 키워드와 클릭이 많은 제목 패턴을 빠르게 확인 → 상품명에 들어갈 핵심 단어를 놓치지 않는 것이 중요

3. 쿠파일럿 (COUPILOT)

  • 공식 사이트: https://www.coupilot.net/
  • 형태: 크롬 확장 프로그램 + 웹사이트
  • 특징: 쿠팡 전용 데이터 분석기

주요 기능

  • 키워드 심층분석: 키워드 통계 + AI 맞춤 판매 가이드 + 상품 분석. 1시간 걸릴 키워드 분석을 10초 만에 완료
  • 카테고리 분석: 해당 카테고리에서 잘 팔리는 상품들의 통계 확인. AI가 잘 팔리는 상품들의 핵심 키워드로 트렌드 분석
  • 키워드 발굴: 축적된 데이터 분석으로 2~3개월 후 순위가 높아질 키워드를 추천
  • 상품 추적: 경쟁 상품의 순위와 조회수를 매일 자동 추적

4. 스마툴 (SmartTool)

  • 형태: 크롬 확장 프로그램
  • 특징: 네이버 스마트스토어와 쿠팡을 동시에 분석

주요 기능

연관 키워드 검색량, 랭킹 순위, 판매량, 판매건수, 매출, 순익, 옵션, 리뷰, 평점, 페이지 조회수, 재고 확인

사용법

Chrome에 추가 → 분석할 쿠팡 상품 페이지 접속 → 확장 프로그램 아이콘 클릭 → 분석 완료

5. 셀러라이프 (SellerLife)

  • 공식 사이트: https://sellochomes.co.kr/sellerlife/
  • 특징: 쿠팡 시장 데이터(시장규모, 판매량, 매출, 클릭수, 전환율) 제공

주요 기능

  • 클릭수, 판매량, 전환율, 소싱가, 입고가, 마진율까지 모든 데이터 표시
  • 매일 사용자마다 중복 없는 추천 키워드 제공
  • 로켓그로스 전용 소싱 기능

6. SMART DATA (스마트데이터)

  • 형태: 크롬 확장 프로그램
  • 무료 사용 가능

주요 기능

판매량 분석, 스토어 분석, 리뷰 분석, 옵션 분석, 실시간 판매 모니터링

7. 네이버 데이터랩 활용

네이버 데이터랩 (datalab.naver.com)

  • 검색어 트렌드: 특정 키워드의 검색량 추이를 기간별, 기기별, 성별로 분류 제공
  • 시즌성 상품인지, 꾸준한 수요가 있는 상품인지 판단
  • 쇼핑인사이트: 쇼핑 카테고리별 클릭량 추이와 인기검색어 TOP 500 확인

사용법

  1. 쇼핑인사이트에서 원하는 카테고리 선택
  2. 기간 설정 후 인기 키워드 확인
  3. 선택한 키워드를 검색어 트렌드에서 상세 검색량 확인
  4. 검색량 추이 그래프로 시즌성/스테디 여부 판단

쇼핑인사이트 실전 활용법

  • 역발상 전략: 500위부터 시작해서 거꾸로 올라가며 틈새 키워드 찾기. 브랜드명이 포함된 키워드나 검색 가능성 낮은 키워드 제외
  • 해외직구 상품 수 비교: 전체 상품 수가 해외직구 상품 수보다 3배 이상 많으면 국내 수요가 더 많다는 뜻 → 국내 소싱 유리
  • 초보 셀러 추천 카테고리: 디지털/가전, 가구/인테리어, 스포츠/레저

네이버 키워드 도구 (searchad.naver.com)

  • 네이버 광고 시스템의 키워드 도구 활용
  • 월간 검색량(PC/모바일 분리), 경쟁 정도, 월평균 클릭수, 클릭률 확인
  • 키워드의 실질적인 검색 수요를 숫자로 확인 → 소싱 판단 근거
